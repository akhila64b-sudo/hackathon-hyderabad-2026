# hackathon-hyderabad-2026
IOT GAS AND SMOKE DETECTION ALARM SYSTEM
An Arduino-based safety monitoring project built and simulated in Tinkercad to detect hazardous gas levels and trigger real-time visual and audible warnings.
## KEY FEATURES:
1.**Real time gas sensing:** samples air quality levels via analog inut.
2.**Visual Alert:** Red LED lights up when gas concentration exceeds threshold.
3.**Audible Warning:** Piezo buzzer sounds during critical levels.
4.**Serial Debugging:** Live diagnostic telemetry printed via serial monitor.
## HARDWARE COMPONENTS:
MICROCONTROLLER: Arduino UNO R3
SENSOR: Smoke detector
OUTPUT DEVICES: Red LED, Piezo Detector
PASSIVES: Resistor(220ohms),Breadboard and jumper wires
SIMULATION PLATFORM: Tinkercad Circuits.
